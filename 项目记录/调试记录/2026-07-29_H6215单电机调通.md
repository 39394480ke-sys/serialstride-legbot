# 2026-07-29 DM-H6215 单电机调通记录

## 目标

使用 STM32F103C8T6、TJA1050 和 USB-TTL，在不依赖 MC02 的情况下完成
DM-H6215 单电机 CAN 通信、控制和反馈闭环验证。

## 调通过程

1. 通过 STM32 ROM Bootloader 和 `stm32flash` 验证串口烧录链路。
2. 使用 bxCAN 静默回环验证 STM32 内部 CAN 控制器和 1 Mbps 位时序。
3. 将总线补齐为两端各 120 Ω，断电测量 CANH-CANL 约 60 Ω。
4. 电机上 24 V 后读取软件版本、控制模式和映射范围。
5. 完成 +0.2 rad/s 和 -0.2 rad/s 的一秒脉冲测试。
6. 解析位置、速度、力矩、MOS 温度和线圈温度反馈。
7. 完成 ±0.5 rad/s 范围的交互式连续速度控制、速度斜坡和 5 秒看门狗。

## 串口命令

| 命令 | 功能 |
|---|---|
| `s` | 显示 CAN ESR、TEC、REC 和 LEC |
| `r` | 读取软件版本 |
| `m` | 读取控制模式 |
| `p` | 读取 `P_MAX` |
| `v` | 读取 `V_MAX` |
| `t` | 读取 `T_MAX` |
| `f` | 显示最后一条解析后的电机反馈 |
| `a` | 解锁运动命令 10 秒 |
| `g` | +0.2 rad/s 运行 1 秒后自动失能 |
| `b` | -0.2 rad/s 运行 1 秒后自动失能 |
| `c` | 解锁后启动交互式连续速度控制，初始目标为 0 |
| `+` / `-` | 每次将目标速度增加/减少 0.1 rad/s |
| `0` | 目标速度回零 |
| `k` | 刷新 5 秒主机看门狗 |
| `x` | 立即请求零速度并失能 |

## 验收结果

原始日志共 591 条记录。最新一次带解析反馈的正转测试结果：

```text
目标速度：+0.200 rad/s
实际速度反馈：+0.186 rad/s
位置反馈：-0.001 rad -> +0.197 rad
力矩反馈范围：-0.003 N·m -> +0.031 N·m
MOS 温度：28°C
线圈温度：26°C
最终输出：TEST_COMPLETE MOTOR_DISABLED
最终 CAN：TEC=0, REC=0, LEC=0, ERROR_ACTIVE
```

反馈速度与目标之间的小差异符合 12 位速度反馈量化。位置增加约 0.198 rad，
与 0.2 rad/s 持续一秒相符。正转、反转、连续变速、回零和看门狗自动失能均
已通过实机观察。

日志前部包含电机未上 24 V 或总线未完成终端匹配时产生的旧 ACK 错误。
最终有效测试的错误计数已归零，这些旧记录不代表当前故障。

## 当前结论

STM32F103 临时台架已经证明以下链路可用：

```text
Mac/Chrome
-> USB-TTL
-> STM32F103
-> TJA1050
-> CANH/CANL
-> DM-H6215
-> 状态反馈
```

速度模式仅用于单电机和底盘驱动链路验证。轮腿机器人进入自平衡阶段后，
轮毂电机最终需要在可靠支撑和严格限矩条件下验证 MIT/力矩控制。
