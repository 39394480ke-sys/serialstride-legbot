# DM-MC02 + H6215 Phase 2.2a 正方向低速测试设计

## 范围

本设计只完成一次由电脑 USB 串口显式触发的 H6215 正方向低速测试：

```text
Arm -> Enable -> +0.2 rad/s / 1000 ms -> 0 rad/s / 200 ms -> Disable
```

本轮不开放负方向、连续速度控制、参数写入、位置控制或力矩控制。正方向实机结果
确认后，再单独设计并开放负方向测试。

## 操作入口

MC02 继续使用板载 USB-C 枚举为 STM32 Virtual ComPort。固件按单字节 ASCII
解析命令，同时接受大小写并忽略回车和换行：

| 命令 | 行为 |
|---|---|
| `S` / `s` | 打印状态，不改变电机状态 |
| `A` / `a` | Arm 10 秒，本身不使能、不运动 |
| `G` / `g` | Arm 有效且全部安全条件满足时，执行一次正方向测试 |
| `X` / `x` | 立即请求零速度并 Disable |

复位、重新上电、只发送 `G`、Arm 超时或测试结束后，系统都保持失能。一次 Arm
最多授权一次 `G`，开始测试时立即消耗授权。

## 串口调试工具设置

在 `serial.baud-dance.com` 中选择：

```text
端口：STM32 Virtual ComPort (cu.usbmodem...)
波特率：115200
数据位：8
校验位：None
停止位：1
流控：None / 关闭
接收格式：ASCII
发送格式：ASCII
HEX：关闭
自动发送 / 循环发送：关闭
行尾：无、CRLF 或 LF 均可
```

USB CDC 实际不依赖所选波特率，`115200 8N1` 用于与旧 F103 台架保持一致。
手动输入框一次只发送一个命令字符。执行顺序是先 `S`，再 `A`，看到
`MOTION_ARMED EXPIRES_MS=10000` 后才发送 `G`。

## 软件结构

### USB 命令入口

ST USB CDC 接收回调只负责把收到的字节写入固定长度环形缓冲区，不阻塞中断，
不直接控制电机。1 ms 主循环消费缓冲区并把有效字符交给运动状态机。

### H6215 协议

现有参数读取、一次 Disable 安全探测和反馈解析继续保留。新增的运动帧严格限制为：

- `CAN ID 1` 的 Enable 系统帧；
- `CAN ID 0x201` 的 4 字节 little-endian 速度命令；
- `CAN ID 1` 的 Disable 系统帧。

目标速度固定为 `+0.2 rad/s`，本轮没有通过串口修改速度、时长或阈值的接口。

### 运动状态机

```text
IDLE_DISABLED
  -> ARMED
  -> ENABLE_WAIT (100 ms)
  -> RUNNING (+0.2 rad/s, 1000 ms)
  -> ZERO_HOLD (0 rad/s, 200 ms)
  -> IDLE_DISABLED
```

`RUNNING` 和 `ZERO_HOLD` 每 10 ms 刷新一次速度命令。所有异常路径统一进入
`FAULT_STOP`：先请求 0 rad/s，再发送 Disable，清除 Arm，最后回到
`IDLE_DISABLED`。`X` 在任何状态都走同一安全停止路径。

## 启动条件

`G` 只在以下条件同时满足时被接受：

- 五项参数均有效，`CAN_ID=1`、`MST_ID=0`；
- 控制模式为 `3 / VELOCITY`；
- 最近 500 ms 内有有效反馈；
- 状态为 `DISABLED`；
- 反馈绝对速度小于 `0.1 rad/s`；
- MOS 和转子温度均低于 `60 C`；
- CAN 不处于 warning、passive 或 bus-off；
- Arm 尚未超过 10 秒且未被消费。

拒绝启动时输出具体原因，不发送 Enable 或速度命令。

## 运行保护

运动期间每个 1 ms 周期检查：

- 反馈更新时间不超过 100 ms；
- 状态为 `ENABLED`；
- 反馈绝对速度不超过 `0.8 rad/s`；
- MOS 和转子温度低于 `60 C`；
- CAN 不处于 passive 或 bus-off；
- 所有必需 CAN 帧成功加入发送 FIFO。

Enable 后允许 100 ms 状态切换窗口；该窗口结束时仍未收到 `ENABLED` 反馈则
安全停止。任何保护触发都会记录原因并发送零速度和 Disable。软件停止不能代替
触手可及的 24 V 物理断电开关。

## 日志与验收

关键日志包括：

```text
MOTION_ARMED EXPIRES_MS=10000
MOTION_START_REQUESTED TARGET=+0.200rad/s
MOTOR_ENABLE_TX_OK
MOTION_RUNNING TARGET=+0.200rad/s DURATION_MS=1000
ZERO_SPEED_HOLD DURATION_MS=200
TEST_COMPLETE MOTOR_DISABLED
```

验收时同时保存 100 ms `[WHEEL]` 与 `HEALTH` 记录。通过条件：

- 用户明确发送 `A` 后再发送 `G`；
- 电机只运行约 1 秒，并按预期方向转动；
- 反馈状态从 `DISABLED` 进入 `ENABLED`，最后回到 `DISABLED`；
- 速度反馈符号为正，幅值接近 `0.2 rad/s` 且不超过 `0.8 rad/s`；
- 温度无异常，CAN 没有进入 passive 或 bus-off；
- 停止后继续观察至少 5 秒，确认速度接近零且保持失能；
- `X` 命令路径在不运动状态下先做一次安全验证。

## 明确不包含

- `-0.2 rad/s` 负方向测试；
- 连续速度模式和速度斜坡；
- 主机 5 秒连续控制看门狗；
- 修改电机内部参数；
- DM4310 或多电机网络。
