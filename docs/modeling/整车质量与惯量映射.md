# 整车质量与惯量映射

## 数据入口

`simulation/mujoco/full_chassis/params/body_mass_map.csv` 是 Phase 1-3 的人工维护
质量属性入口。`inertials.yaml` 和当前 `robot_dynamics.xml` 是迁移前生成快照，
不得作为独立数据源手工修改。

由于 `robot_geometry.xml` 已升级为包含 tendon、模态 actuator、11 个 keyframe
和 slide 归一化的权威 geometry，旧同步器尚未完成迁移。当前
`scripts/sync_inertials.py` 的普通模式与 `--check` 都会在写文件前以
`MIGRATION REQUIRED` 停止，避免重复创建或覆盖机构语义。

CSV 的镜像行通过 `mirror_of` 继承质量和三个主惯量，但保留右侧 body 自己的
局部 COM 与镜像惯量坐标。只改变质量且几何不变时，
`uniform_mass_scale` 按质量比例缩放惯量。若零件形状或安装位置变化，应更新
SolidWorks/网格给出的 COM 与惯量，而不能继续使用均匀缩放近似。

## 刚性总成划分

| 分组 | 当前内容 | 当前模型质量 |
| --- | --- | ---: |
| `base_link` | 中央底盘、4 台关节电机、4 个电机侧同步轮及固定部件 | 2.200000 kg |
| 左侧主要连杆 | `link_002` 至 `link_009` 中的连杆与闭链辅助 body | 0.171547 kg |
| 右侧主要连杆 | 左侧连杆的镜像 body | 0.171547 kg |
| 左轮组 | `link_010` | 0.600000 kg |
| 右轮组 | `link_025` | 0.600000 kg |
| 左气弹簧 | `link_011`、`link_012`、`link_013` | 0.013225 kg |
| 右气弹簧 | `link_022`、`link_023`、`link_024` | 0.013225 kg |

当前模型总质量为 `3.76954478618 kg`。这是模型文件的已验证事实，不等于
精确的实物整机称重结果。

## 证据等级

- **B**：主要 body 的质量沿用 SolidWorks 设置值；用户明确观察其与实物大致
  相符，但没有逐 body 称重。
- **C**：COM、惯量和轻量闭链辅助件来自现有网格几何计算，具有几何依据，
  尚未独立验证。
- **D / PROVISIONAL**：气弹簧没有提供实物质量；当前每侧约 `13.225 g` 只用于
  建立可运行基线，不作为物理证据。

未建模螺栓、轴承和其他随动硬件不声明为零质量。以后获得更好的总成质量时，
应将它们合并到保持固定相对位姿的 `base_link` 或相应运动连杆，无需为每颗
紧固件建立独立 body。

## 已验证与未验证

已验证：25 个 body 均有显式正质量、正定且物理平衡的主惯量；左右镜像质量
和主惯量一致；模型在 MuJoCo 3.9.0 中关闭 `balanceinertia` 后可编译；7 个
keyframe 的整机 COM 可由审计脚本复现。

尚未验证：精确实物整机重量、单根气弹簧重量、遗漏紧固件的质量分配，以及
相同姿态下的 SolidWorks/实物整机 COM。因此当前不能声称满足总质量误差
`<= 2%` 或 COM 各轴误差 `<= 5 mm`。

## 后续更新触发条件

当前 CSV 是第一版机械结构的基础动力学基线，暂不继续追求严格实物质量和
COM 验收。第二版机械结构完成并基本定型后，重新核对 body 与实物刚性总成的
对应关系，并更新 `body_mass_map.csv` 中受影响的质量、COM、惯量、来源和置信度。

第二版更新时优先补充：新底盘总成质量、新增或移位部件的归属、单根气弹簧
质量，以及同一姿态下的 SolidWorks 整机 COM。更新前必须先完成
geometry-to-dynamics 生成器迁移；之后才能恢复同步和质量审计。不得直接沿用
本版的 `PROVISIONAL` 气弹簧参数作为最终数据。
