# DM-H6215 单电机 Bring-up

这里保存 DM-H6215 单电机台架的阶段性结论和原始测试数据。源代码只保存在
[`firmware/stm32f103-h6215-bench/`](../../../firmware/stm32f103-h6215-bench/)，
本目录不复制源码。已验证二进制通过 GitHub Release 发布。

## 当前状态

截至 2026-07-29，已完成一台 DM-H6215 的 STM32F103 临时台架验证：

- CAN 物理链路、1 Mbps 通信和双端 120 Ω 终端匹配正常。
- 参数读取、使能、失能、正反转和连续速度控制正常。
- 位置、速度、力矩、MOS 温度和线圈温度反馈解析正常。
- 速度斜坡、5 秒主机看门狗和异常自动失能正常。
- 当前可用固件对应 `v0.1.0` GitHub Release。
