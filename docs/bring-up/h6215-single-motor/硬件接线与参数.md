# H6215 台架硬件接线与参数

## 已确认设备

| 项目 | 配置 |
|---|---|
| 电机 | 达妙 DM-H6215 |
| 临时主控 | STM32F103C8T6 Blue Pill |
| CAN 收发器 | TJA1050 模块 |
| USB-TTL | CH340 |
| 电机电源 | 24 V 直流电源 |
| 串口 | 115200, 8N1 |
| 示例 macOS 设备名 | `/dev/cu.usbserial-XXXX` |

串口设备名会随 USB 接口或扩展坞变化。烧录前应先执行：

```bash
ls /dev/cu.usbserial-*
```

## 接线

### USB-TTL 与 STM32

```text
USB-TTL TXD -> STM32 PA10 / USART1_RX
USB-TTL RXD <- STM32 PA9  / USART1_TX
USB-TTL GND -> STM32 GND
USB-TTL 3V3、5V均不接
```

### STM32、TJA1050 与电机

```text
STM32 PA12 / CAN_TX -> TJA1050 TXD
STM32 PA11 / CAN_RX  <- TJA1050 RXD
STM32 5V             -> TJA1050 VCC
STM32 GND            -> TJA1050 GND
TJA1050 CANH         -> H6215 CANH
TJA1050 CANL         -> H6215 CANL
```

TJA1050、STM32 和 24 V 电源负极必须共地。电机主功率由 24 V 电源供给，
不能由 USB 或 STM32 供电。

## CAN 终端

CAN 总线两个物理末端各使用一只 120 Ω 终端电阻。全部断电后测量
CANH 与 CANL，当前台架约为 60 Ω，符合两只 120 Ω 并联的结果。

## 烧录

1. 关闭 H6215 的 24 V 电源并断开 Chrome 串口。
2. 设置 `BOOT0=1`、`BOOT1=0`，按 `RESET`。
3. 执行：

```bash
SERIAL_PORT=/dev/cu.usbserial-XXXX

stm32flash -b 115200 \
  -w firmware/stm32f103-h6215-bench/build/stm32f103_boot_test.bin \
  -v "$SERIAL_PORT"
```

4. 写入和校验达到 100% 后，设置 `BOOT0=0`、`BOOT1=0`，再按 `RESET`。

## 安全要求

- 电机定子必须可靠固定，转子悬空并远离手、工具和线缆。
- 上电前确认 CANH/CANL、24 V 正负极和共地关系。
- 调试期间保持物理断电开关触手可及，软件失能不能代替物理断电。
- 每次复位后先发送 `m` 确认速度模式，再允许使能。
- 当前固件速度限制为 ±0.5 rad/s，反馈速度超过 ±0.8 rad/s 会触发保护。
- MOS 或线圈温度达到 60°C、状态异常或 CAN 发送失败时自动零速并失能。
