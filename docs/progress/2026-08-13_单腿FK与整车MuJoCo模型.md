# 2026-08-13 单腿正运动学与整车 MuJoCo 几何模型

## 阶段目标

建立可测试的单腿正运动学与工作空间模型，并将 CAD 导出整理为可稳定
调试的整车闭链 MuJoCo MJCF。

## Track A：单腿正运动学

等效退化五连杆参数：

```text
l1 = l4 = 0.110 m
l2 = l3 = 0.132 m
l5 = 0 m
```

FK 与原始电机角度转换的 2 项单元测试通过。在两个关节的软限位内，
181 x 181 的 32,761 个采样状态全部有效：

```text
Hx = -37.33 .. +37.07 mm
Hz = -176.16 .. -93.07 mm
```

上述工作空间是模型推导结果。本 Stage 明确豁免独立多姿态 SolidWorks/实物
坐标验证，因此不宣称实物精度达到 `<=2 mm`。

## Track B：整车 MuJoCo

模型坐标约定为 `+X` 前、`+Y` 左、`+Z` 上。主动关节接口固定为：

```text
left_joint_a
left_joint_b
right_joint_a
right_joint_b
```

轮轴为 `left_wheel_joint` 和 `right_wheel_joint`。四个主动关节的正方向统一为
伸腿方向，使用约 `0.132318159 rad` 的 `ref`，控制值 0 对应 `CALIB_MID`。

静态结构与动态验证结果：

| 项目 | 结果 |
| --- | ---: |
| Body | 25 |
| Joint | 24 |
| Equality connect | 6 |
| Actuator | 4 |
| Keyframe | 7 |
| 声明总质量 | 3.76954478618 kg |
| Keyframe 闭链残差 | 约 `1e-9 m` |
| 阶跃最大残余速度 | 约 `2.01e-6 rad/s` |

用户在 MuJoCo 中确认了坐标轴、A/B 映射、左右镜像、气弹簧连接、轮轴共线及
Key 0-6。Track A 与 Track B 的三个参考姿态和四个中间姿态高度一致。

## 实物观察与未验证边界

- SolidWorks 中收缩、中间、伸展角约为 `5.79 deg`、`25.48 deg`、`44.69 deg`；
  当前 CAD 导出姿态约为 `33.07 deg`。
- 用户观察整体重量正确，但这不等于各 link 质量分配、质心和惯量已独立验证。
- 未生成 URDF；闭链几何直接使用 MJCF。
- 气弹簧动力学、地面接触、承重站立和控制算法属于后续 Stage。
