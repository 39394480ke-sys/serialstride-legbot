# 2026-08-16 整车 MuJoCo 基础动力学模型

## 阶段目标

将整车闭链 geometry 升级为带质量惯量、重力、六电机直接力矩输入和地面
接触的基础动力学模型，为后续参数辨识、承重控制和强化学习提供可重复的
数值基线。

本阶段按修订后的范围完成。气弹簧参数接口已经保留，但气弹簧力学明确延期，
不进入当前基础动力学模型。

## 模型职责

三层模型继续保持明确边界：

| 文件 | 职责 | SHA-256 |
| --- | --- | --- |
| `robot_source.xml` | 不可修改的 CAD 原始导出 | `9387924d3dad5ea2097e8953228b8de0cfd61661b36b10f039596c25b4e14d55` |
| `robot_geometry.xml` | 权威闭链、坐标、范围和调试接口 | `e7e1f21c22bbcc8846be8548e071819e72ccfad49df203704b56205417b800ea` |
| `robot_dynamics.xml` | geometry 与参数表确定性生成的动力学模型 | `ce3a19958bca0bb0207fce83ccfb6cecd9fca28ffa8bf22dedb3101321f45f46` |

本阶段没有重新生成或修改权威 geometry。派生 dynamics 包含：

- 25 个 body、24 个 joint 和 6 个 equality connect；
- 4 个 fixed tendon、11 个 keyframe 和 2 个传感器；
- 25 个显式质量惯量元素，总质量约 `3.76954478618 kg`；
- 4 个腿部直接力矩 motor 和 2 个轮部直接力矩 motor；
- `balanceinertia=false`、重力和三个独立测试场景。

geometry 中的四个模态位置执行器继续用于机构调试，不进入 dynamics。动力学
模型中的六个 motor 使用直接关节力矩接口。

## 执行器与方向

DM-J4310-2EC V1.2 使用输出端额定/峰值力矩 `3.5/12.5 Nm`，DM-H6215
使用 `1/2 Nm`。这些厂家参数用于当前理想力矩源的饱和边界，不代表已在当前
供电、驱动、速度和温度条件下完成实物复现。

世界坐标 `+X` 为整车前方。MuJoCo 中已经验证：

```text
left_wheel_motor  < 0
right_wheel_motor > 0
```

时整车向世界 `+X` 运动，反号组合向 `-X` 运动。

## 场景与数值验证

本阶段生成并验证三个场景：

- `scenes/fixed_base.xml`：固定基座的接口和闭链检查；
- `scenes/free_ground.xml`：自由整车与地面接触；
- `scenes/drop_test.xml`：低高度落地数值回归。

初始最大闭链残差约为 `1.43e-9 m`。free-ground 和 drop 的全部 11 个
keyframe 均通过 5 秒有限状态、接触和闭链检查，最大动态闭链残差约为
`0.0496 mm`。用户在 MuJoCo Desktop 中检查全部 key，未观察到穿地、异常
抖动、数值爆炸或可见闭链分离。

上述结果只构成基础动力学数值基线，不代表实物高保真验证完成。

## 气弹簧边界

气弹簧的物理行程约 `23 mm`，厂家标称力为 `60 N`。当前缺少标称力公差、
预载、刚度、阻尼和完整力-行程曲线，因此 `params/gas_spring.yaml` 保持
`enabled: false`。当前基础动力学和第一版强化学习环境都不施加气弹簧力。
